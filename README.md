## ⭐ Featured Projects

### 🔥 Mini Redis — Java

**A Redis-inspired in-memory key-value server built from scratch in Java.**

Built to understand how **client-server systems, command processing, concurrency and data stores** work internally.

**Implemented**

* 🔌 TCP client-server communication
* 📡 RESP-style command parsing & responses
* ⚡ Concurrent key-value storage
* 🧩 `SET` · `GET` · `DEL` · `EXISTS` · `KEYS` · `PING` · `FLUSHALL`
* ⏱️ Key expiration & TTL
* 💾 File-based persistence
* 🛑 Graceful shutdown & data saving
* 🧪 **16 passing JUnit tests**
* 📦 Maven project structure

**Tech:** `Java` `TCP` `Concurrency` `Maven` `JUnit` `File I/O`

🔗 **[View Repository →](https://github.com/souumyajha/mini_Redis)**
