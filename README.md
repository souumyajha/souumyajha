## 🧩 Featured Projects

### 🔥 Mini Redis — Java

A **Redis-inspired in-memory key-value server built from scratch in Java**, created to understand how client-server systems and data stores work internally.

**Implemented:**

* TCP client-server communication
* RESP-style command parsing and responses
* Concurrent key-value storage
* `SET`, `GET`, `DEL`, `EXISTS`, `KEYS`, `PING`, `FLUSHALL`
* Key expiration and **TTL**
* File-based data persistence
* Graceful shutdown and data saving
* Maven project structure
* **JUnit test suite with 16 passing tests**

**Tech:** Java • TCP Networking • Concurrency • Maven • JUnit • File I/O

🔗 [View Repository](https://github.com/souumyajha/mini_Redis)
